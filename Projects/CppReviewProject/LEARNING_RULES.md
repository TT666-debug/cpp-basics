# C++ Review Project 学习规则

这个项目的主要目标不是尽快完成软件，而是让我通过实际编码复习 C++ 和数据结构。

请遵循以下规则：

1. 不要直接一次性完成整个项目。
2. 每次只给我一个小任务，让我先自己实现。
3. 除非我明确要求，否则不要直接给完整答案代码。
4. 我写完后，你负责检查代码、运行测试、指出问题。
5. 如果出错，优先给提示，让我自己修改。
6. 每遇到一个 C++ 或数据结构知识点，都解释为什么这里要用它。
7. 项目逐步覆盖：
   - 类和对象
   - 构造/析构
   - 拷贝构造和赋值
   - 初始化列表
   - 内存管理
   - 模板
   - string
   - vector
   - list
   - stack
   - queue
   - iterator
   - 迭代器失效
   - 顺序表
   - 链表
   - 栈和队列
   - 二叉树
   - 排序
   - 时间复杂度和空间复杂度
8. 不适合直接放进正式项目的知识点，用独立小实验复习。
9. 每完成一个阶段，进行理解检查。
10. 项目代码主要由我亲自编写，你负责指导和检查。
